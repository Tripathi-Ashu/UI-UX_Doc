# UI Components

These reusable elements were built in Figma as **components with variants**, so a change made once is reflected across the entire app.

![Components](/img/design-system/components.png)

## Buttons

| Type | Style | Examples |
|---|---|---|
| **Primary** | Saffron fill, white text | Continue, Verify and continue, Login, Buy Now, Place order |
| **Secondary** | White fill, saffron outline | Add to bag, Move to Bag, Edit |
| **Disabled** | Light grey fill, muted text | Continue (before a number is entered) |
| **Text link** | Saffron or underlined text | Forgot Password, Need Help, Skip for now |
| **Social** | Circular outlined icon | Google, Facebook, Email |

## Input Fields

- Outlined, rounded field with a muted placeholder
- Label above the field and helper or error text below
- Six separate boxes for OTP entry
- Variants: default, filled and error (for example, an incorrect password)

## Product Card

- Product image with rating badge and wishlist heart
- Product name, selling price, MRP (strikethrough) and discount in green
- Contextual action such as **Move to Bag**

## Bottom Navigation

Four tabs: **Home, Wishlist, Bag and Profile**. The active tab is highlighted in saffron, and inactive tabs use neutral grey.

## Layout Elements

| Component | Purpose |
|---|---|
| Status bar and gesture bar | Reusable device chrome kept consistent across all screens |
| Category chips | Top Wear, Bottom Wear, Footwear, Accessories, Bags and Sports |
| Tabs | All, Men, Women and Kids |
| Size selector | S to XXL, with the selected size filled in saffron |
| Color swatches | Product color selection |
| Quantity stepper | Increase or decrease item quantity in the Bag |
| Radio option | Payment method and Google account selection |
| Price details card | Itemized breakdown of totals, discounts and delivery |
