# Color Palette

The visual identity is built around a single warm accent, **Saffron**, supported by a neutral ink scale and clear status colors. One accent color keeps the interface focused: every primary action and every selected state uses the same color, so users always know where to tap next.

![Color palette](/img/design-system/color-palette.png)



## Brand Colors

| Token | Approx. HEX | Usage |
|---|---|---|
| **Saffron 700 (Primary)** | `#B54708` | Primary buttons, active tab, selected size and color, selected radio, links and highlights |
| **Saffron 50** | `#FFF4E8` | Soft tint for selected cards and highlighted rows (for example, the selected payment method) |

## Neutral Colors

A scale of ink and surface tones supports text, borders and backgrounds.

| Role | Usage |
|---|---|
| **Ink (darkest)** | Headings, product names and prices |
| **Ink (dark to mid)** | Body text, icons and labels |
| **Ink (light)** | Secondary text, placeholders and struck-through MRP |
| **Border** | Input outlines, card outlines and dividers |
| **Surface** | Image placeholders, disabled fills and tiles |
| **Background** | Screen and card backgrounds |

## Status Colors

| Status | Usage |
|---|---|
| **Success (green)** | Savings messages and discount labels (for example, "You are saving on this order") |
| **Error (red)** | Validation errors and destructive actions such as Log out |
| **Warning (amber)** | Low stock alerts and expiring offers |

## Design Rationale

- A single accent color creates a clear **visual hierarchy** and a recognizable brand.
- Saffron is warm and energetic, which suits a fashion and shopping context.
- Green is reserved for savings so that positive financial feedback stands out.
- Neutral surfaces let product photography remain the focal point.
