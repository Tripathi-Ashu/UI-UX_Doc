# Week 1–2: UI/UX Fundamentals

**Period:** 16 September 2026 – 29 September 2026

## Topics Covered

- The difference between UI and UX, and how the two work together
- The design thinking process: Empathize, Define, Ideate, Prototype, Test
- User research basics: personas, user journeys and pain points
- Visual design principles: hierarchy, contrast, alignment, spacing and consistency
- Mobile design fundamentals: platform guidelines, touch targets and safe areas

## Tools Used

- **Figma:** interface and workspace orientation
- **FigJam:** brainstorming and early user flow mapping

## Key Learnings

- Good design is not only visually appealing; it must be **usable** and purposeful.
- Every screen should have one clear purpose and one primary action.
- Consistent spacing on an 8 px grid gives a design a professional finish.
- Starting with wireframes before color keeps decisions focused on structure and usability.
