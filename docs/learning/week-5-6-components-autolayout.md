# Week 5–6: Components, Variants and Auto Layout

**Period:** 14 October 2026 – 27 October 2026

## Topics Covered

- **Auto layout:** padding, spacing, direction and resizing behavior
- **Components and instances:** how a main component drives its copies
- **Variants and properties:** managing states such as default, disabled and error
- Color, text and effect styles
- Variables and design tokens
- Assembling a compact design system

## Tools Used

- Auto layout
- Components and variants
- Local styles and variables

## Key Learnings

- Auto layout makes screens adapt automatically when content changes.
- Editing a main component updates every instance across the app.
- Variants let a single component manage several states, such as an enabled and disabled button.
- A design system speeds up work and keeps the product visually consistent.
