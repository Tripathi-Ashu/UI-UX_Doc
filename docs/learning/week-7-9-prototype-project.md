# Week 7–9: Wireframing, Prototyping and Final Project

**Period:** 28 October 2026 – 16 November 2026

## Topics Covered

- Low-fidelity wireframing and user flow design
- Information architecture for an e-commerce app
- Prototyping: triggers, interactions and transitions
- Smart animate and overlays
- Converting wireframes into a high-fidelity UI
- Design review, feedback and iteration
- Documentation and handoff basics

## Tools Used

- Figma Prototype mode
- Figma Dev Mode for reviewing specifications
- Docusaurus for the documentation website

## Key Learnings

- Defining the **user flow** first makes screen design faster and more coherent.
- A prototype allows the design to be tested like a real application.
- Feedback and iteration lead to measurable improvements in clarity.
- Clear documentation makes design work understandable to reviewers and teams.

## Final Project

The final project for this phase is a **Fashion E-commerce Mobile App** with 11 screens. Full details are in the [Project section](../project/overview).
