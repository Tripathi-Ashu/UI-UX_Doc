# Week 3–4: Figma Basics

**Period:** 30 September 2026 – 13 October 2026

## Topics Covered

- The Figma workspace: canvas, layers panel and properties panel
- Frames, shapes, text and vector tools
- Layout grids and constraints for responsive behavior
- Alignment, distribution and spacing tools
- Fills, strokes, images and effects such as shadows
- Exporting assets in PNG, SVG and PDF formats

## Tools Used

- Figma Design (Frame, Rectangle, Text and Pen tools)
- Plugins for placeholder images, icons and sample content

## Key Learnings

- Every mobile screen should start from a **device frame** so proportions stay realistic.
- Correct constraints keep elements stable when a frame is resized.
- Clear layer naming saves significant time in larger files.
- Exporting at **2x** produces sharp images for documentation and handoff.
