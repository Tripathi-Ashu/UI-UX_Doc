# Project Overview: Fashion E-commerce App

## Problem Statement

Shoppers on mobile fashion apps often face slow sign-in, cluttered navigation and lengthy checkout flows, which lead to abandoned carts. The goal of this project was to design a **fast, clear and mobile-first shopping experience** in which a user can log in within a few taps, find a product, add it to the bag and place an order with confidence.

## Target Users

- Fashion shoppers aged 18–35
- Mobile-first users in India
- Customers who prefer UPI and Cash on Delivery

## Key Features

| Feature | Description |
|---|---|
| **Quick login** | Mobile OTP, email and password, or Google sign-in |
| **Home** | Search, categories, promotional banner, deals, trending items, top brands and recommendations |
| **Product detail** | Image gallery, color and size selection, delivery check and similar products |
| **Wishlist** | Save products and move them to the bag in one tap |
| **Bag** | Quantity control, coupons and a transparent price breakdown |
| **Checkout** | Address, multiple payment methods and a secure payment assurance |
| **Profile** | Orders, wallet, saved addresses, returns and support |

## Scope

- **11 mobile screens** designed for the iPhone frame
- Low-fidelity **wireframes** and high-fidelity **final UI** for each screen
- A reusable **design system**
- An **interactive prototype** in Figma
